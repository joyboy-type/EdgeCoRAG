# v3 优先级操作定义（先登记规则，后重算）

优先级定义为事后设定。此规则取代 v2 的重叠条件作为本轮操作分区；v1/v2 表与原始日志保留。

先检查 S0/S1 配对、正确标记和 top3→GT 联接输入。真正缺输入归“不可判定”，单列；不得把正确题归入缺输入。
输入完整时严格按以下顺序，命中即停止：
1. S0 对且 S1 错 → 检索伤害。
2. top3 不含 GT 且 S1 错 → 未检索到。
3. top3 含 GT 且 S1 错 → 检索到但答错。
4. 其余 → 无关但未伤害。

“检索伤害”是配对结果的操作标签，不作因果解释；第四类包含所有 S1 正确题，不表示已证明证据无关。“能力替代”不进入分区。
固定 frozen_test/quality 每模型 1033 题；解析失败与生成失败沿用原错误标记，保留分母，不重解析。每行恰一标签；四完整输入类之和加不可判定必须为1033，若无缺输入则四类之和必须为1033。

描述性、未预注册：对固定1033题的564个查询/GT图像关联分量，有放回整簇bootstrap 10000次、seed42，按题加权；分类占比用全False参考计算区间，不是模型准确率差。同时提供未校正95%区间及全25格家族保守同时区间（Bonferroni，兼容Holm全家族矩形，非逐项Holm反演）。不据此推断因果或等效性。
