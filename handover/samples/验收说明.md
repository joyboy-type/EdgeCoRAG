## 4. ⚠️ 图片是否经过重新编码：**是，全部是重编码产物**

这一点必须明确，先前文档的说法是错的。

| 项 | 事实 |
|---|---|
| 数据集原始字节能否取得 | **不能**。实测 `im.fp` / `_data` / `data` / `filename` **全为 None** |
| 落盘字节来源 | **JPEG quality=95 重编码** |
| 是否确定性 | ✅ 是。同一张图在多次独立加载中哈希完全一致（`test_hash_stability.py` 验证 3 次） |
| 索引哈希与文件是否一致 | ✅ 一致，且**参与哈希的就是落盘的那份字节**（已逐条回读校验） |
| 对集合匹配的影响 | **无影响**。GT 与候选使用同一口径，匹配为双射；JPEG95 与 PNG 两口径算出的命中率同为 55.9% |

显式声明位置：`sample_meta.json` → `encoding`。

## 5. GT 图片的可解析映射（S2 可跑）

**已提供**，无需另取文件：

| 字段 | 位置 | 内容 |
|---|---|---|
| `gt_evidence_ids` | `scoring_only` | 按协议实际使用的 GT ID 列表 |
| `gt_evidence_refs` | `scoring_only` | **完整图片引用**（`path` + `sha256` + 尺寸），B 直接用 |
| `gt_evidence_ids_all` | `scoring_only` | 数据集中全部 GT 的 ID（未经场景规则截断），用于审计 |
| `gt_on_official_pool_ranks` | `scoring_only` | 该题 GT 落在候选池的位置，空数组表示未命中 |

**S2 缺项检查**：6 题所需 GT 文件**全部已落盘**，数量与数据集**真实数量一致**
（常规 5 张、Incomplete 1 张），**未复制、未补图凑数**。
→ **可跑 S2，无缺项。**

> 若要跑全量 S2，仍需自行从数据集取其余题目的 GT（本包只含 6 题）。
