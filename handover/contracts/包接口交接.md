# 与 B 的接口交接：分条件证据包

> 说明各 S1/S2/S3 包的字段、排序、媒体根目录、版本与哈希，
> 使 B 能按固定版本直接接收并运行。

---

## 1. 包标识与版本

| 字段 | 取值 | 说明 |
|---|---|---|
| 包名 | `<split>_<condition>` | 如 `frozen_test_s1` |
| 数据版本 | `uclanlp/MRAG-Bench` @ `43620fde4044bb150e158c67ad7af6b6b11e1da2` | CC-BY-4.0 |
| 题单版本 | `splits/<split>.v2.txt`（种子 `20261015`） | 题单哈希见 `split_manifest.v2.json` |
| 包版本 | 见各包 `package_meta.json` 的 `package_version` | — |
| 内容摘要 | `content_digest`（sha256 over 图片文件，范围见 `content_digest_scope`） | 非空，已含 S3 |

条件定义：

| 条件 | pool_id | 证据数 | 占位符 | is_oracle |
|---|---|---|---|---|
| S1 | `official_retrieved_top3` | 3（含 Incomplete） | 4 | false |
| S2 | `gt_evidence` | 常规 5 / Incomplete 1 | 6 / 2 | true |
| S3 | `pure_distractor_d1` | ≤3（正式只取满 3 张的题） | 1+n | false |

## 2. qid / 证据 ID / rank / 排序

- **qid**：`mragb:<raw_id>`；`raw_id` 是 HF `id` 原样字符串（如 `'0'`）。
- **证据 ID**：`<qid>#<role><rank>`：
  - 查询图 `role=q`、rank 空；
  - S1 `role=official_retrieved`、rank 0..2（**既有排名**，即官方候选顺序）；
  - S2 `role=gt`、rank 0..4（常规）/ 0（Incomplete）；
  - S3 `role=distractor`、rank 0..2。
- **S1 排序**：按官方既有排名升序（`retrieval_rank` 字段原样保留）。
- **S2 排序**：按 GT 顺序（数据集内 `gt_images` 顺序，无语义）。
- **S3 排序**：确定性顺序 = 错误选项顺序（A→D 排除正确项）→ 来源题 qid 数值序；
  S3 无检索，`retrieval_rank=null`，顺序由 `evidence_order` 数组位置 + `rank` 表达。

## 3. 媒体根目录与路径

- 所有 `path` 均**相对包根目录**（不绑定盘符），形如 `images/<raw_id>/<role>_<raw_id>_<rank>.jpg`。
- B 把包目录放到任意位置，`path` 拼到包目录之后即可定位。
- 图片为 **JPEG q95 重编码**（原始字节取不到），哈希与落盘字节同源；见 `package_meta.json` 的 `encoding`。

## 4. 题目、选项、评分字段与审核记录的对应

| 区 | 字段 | 用途 | 可否进入模型输入 |
|---|---|---|---|
| `task_payload.question` | 题干 | 组装 prompt | ✅ |
| `task_payload.choices` | A/B/C/D 四选项 | 组装 prompt | ✅ |
| `question_image` | 查询图引用 | 第 1 张图 | ✅ |
| `evidence_order` | 有序证据引用 | 第 2..n 张图 | ✅（`used_in_prompt=false` 的除外） |
| `scoring_only.gold_choice` | 正确选项字母 | 仅评分 | ❌ |
| `scoring_only.answer_text` | 正确选项文本 | 仅评分 | ❌ |
| `scoring_only.gt_evidence_*` | GT 引用/命中位点 | 仅评分/Oracle | ❌ |
| `semantic_review.csv`（仅 S3） | 逐候选三态审核记录 | 审计/追溯 | ❌（不进 prompt） |

**纪律**：`scoring_only` 与 `semantic_review.csv` 的字段**绝不进入模型消息**；
模型输入只有 `task_payload` + 图片。

## 5. S3 审核记录（CSV，可追溯）

`samples` 无 S3；各 S3 包含：

| 文件 | 内容 |
|---|---|
| `semantic_review.csv` | 全部候选：`qid`、`final_evidence_id`、`src_question`、`src_gt_idx`、`semantic_verdict`、`justification`、`fate`（kept / excluded_*） |
| `review_checklist.csv` | **人工审核清单**：`qid`、题目、四选项、正确项、`final_evidence_id`、图片路径、`source_question`，以及**待人工填写的** `semantic_verdict` / `review_basis` / `reviewer` / `reviewed_at` |

**语义三态语义**：`支持`（图片支持正确答案，剔除）/ `不支持`（确认不支持，可进入纯干扰）/
`无法判断`（排除，不标为纯干扰）。

**注意**：`semantic_review.csv` 的 `semantic_verdict` 目前是**自动构造规则的初判**，
**不等于人工语义审核**。正式 S3 以 `review_checklist.csv` 人工填写后为准。
B 可做可追溯转换，但**转换不能替代语义审核**。

## 6. 版本与哈希核验

```bash
# 1) 数据与题单
python a-side/scripts/verify_split.py --version v2      # 切分 18 项不变量

# 2) 证据包（按条件）
python a-side/scripts/verify_packages.py --dir packages/<name> --condition <S1|S2|S3>

# 3) 内容摘要核对
python -c "import json;print(json.load(open('packages/<name>/package_meta.json'))['content_digest'])"
# 与 a-side/plans/EXTERNAL_ARTIFACTS.json 中对应包条目比对
```

**逐文件 SHA-256 清单**：每包 `evidence_index.csv`（查询图 + 证据图）与
`file_hashes.csv`（S3 包，finalize 后生成）。
