# 独立检索语料：访问与许可结论（corpus_readiness.md）

核验日期：2026-10-17。本轮只读公开网页 / 仓库 / HF 元数据，未下载语料、未下载图片包或 PDF，
未运行作者代码或 judge。逐项来源见同目录 `corpus_access_and_license.csv`。

## 结论：**仍受阻，暂不能进入独立检索协议设计**

一句话：**本机网络无法访问 Google Drive（语料唯一官方入口），且该语料包的许可从未声明。**
两项叠加使「MRAG 独立检索」路线在拿到语料与许可确认前，不具备可执行条件。

> 注意口径：这是「MRAG 独立检索语料」（官方 image corpus 压缩包）的结论；
> **不是** MMDocRAG 第二数据集（那是 B 侧任务），也不是本轮已完成的 S1 官方候选 top-3。

## 2. 与其它组件许可的边界（避免混为一谈）

| 组件 | 许可 | 能否据此授权语料再分发 |
|---|---|---|
| HF 数据集 `uclanlp/MRAG-Bench` | **cc-by-4.0**（已核实） | ❌ 不能。该许可是数据集本体；独立语料包是另一发布物 |
| MRAG-Bench 评测代码仓库 | **license=null**（GitHub API 未识别 SPDX） | ❌ 代码许可未声明 |
| utility-mrag 作者代码 | MIT（已核实） | 仅代码，与图像无关 |
| 独立语料压缩包 | **未声明** | ❌ 无依据 |
| 官方候选产生所用的检索器/模型 | **未说明** | ❌ 见 `official_pool_provenance.md`，官方未公开 |

**关键区分**：代码许可（如 MIT）≠ 图像可再分发；HF 数据集的 CC-BY-4.0 ≠ 语料包的许可。

## 4. 对下一轮实验的含义

- **在阻塞解除前**：独立重检索路线（R07/R33 的检索指标部分）**不能启动**，也不应把「官方候选 top-3」改名为自主检索结果。
- 若下一轮需要独立检索，必须**先解决语料访问与许可**，再冻结检索协议与资源预算。
- 本轮 S1 仍为「已发布官方候选 top-3」，名称与分数不覆盖。

## 5. 已知限制（如实声明）

- 规模「未核实」就是未核实，不写成实测；HF `usedStorage`（≈8.0 GiB）与本地 parquet 实测（4.0 GiB）是**数据集本体**的不同口径，不是语料包体积。
