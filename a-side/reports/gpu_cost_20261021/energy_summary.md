# GPU 能耗汇总（2026-10-21｜E3 pilot，本地计算，未开机）

输入（只读，sha256 均核对）：`device_samples.jsonl`（570 记录）、`index_residency.json`、`switches.json`。
GPU 身份：**NVIDIA GeForce RTX 3090**（24 GB，来自 `switches.json` 的 runtime 字段，非本轮实测）。

## 1. 采样统计（口径：只统计 `power_W` 非空行）

| 项 | 值 |
|---|---|
| 采样点数（power_W 非空且可解析） | **570 / 570**（空/坏 = 0） |
| 均值功率 | **187.36 W** |
| 最小功率 | 31.25 W |
| 最大功率 | **312.17 W**（采样到的最大值，不是连续峰值） |
| 窗口时长 | **83.54 s**（末 epoch − 首 epoch = 1792541436.185 − 1792541352.644） |
| **电量** | **4.3478 Wh** = 187.36 × 83.54 / 3600 |

## 2. 三条限制（写死）

1. **窗口约 83.5 秒，仅 E3 pilot，不代表整轮会话**——这是 pilot 里一个 83.5 s 的采样段，不是完整 benchmark 的功耗。
2. **是 nvidia-smi 采样的 GPU 功耗估计，不含 CPU/内存/网络，不是整机能耗**——只有 GPU 板卡功耗，不能当系统功耗引用。
3. **点采样非连续积分**——"电量 = 均值 × 窗口 / 3600"是矩形近似，不是功率对时间的真实积分；31.25 W（空闲）到 312.17 W（峰值）之间的瞬态只被 570 个离散点近似。

## 3. 交叉核对

| 项 | 结果 |
|---|---|
| `index_residency` 是否覆盖索引加载 | **否**：`storage = resident CPU NumPy matrix`，`vram_delta_bytes = 0`，`device_used_bytes` 前后都是 1,048,576 → **索引驻留 CPU、无 GPU 索引拷贝**，采样窗口里没有"GPU 索引加载"这一事件可覆盖 |
| `switches` 时间戳是否落在采样窗口 | **是**：switch 的 before/after epoch 范围 `[1792541371.80, 1792541421.28]` 完全落在采样窗口 `[1792541352.64, 1792541436.19]` 内 → 3 次模型切换（coexist_gemma4_e4b→gemma4_e2b 等）期间的功耗**有采样覆盖** |
| 无采样区间 | 本窗口内未发现缺口；窗口外（83.5 s 之前/之后）**无功率数据，未计入** |

## 4. 结论口径（论文引用的唯一合法写法）

> 在 E3 pilot 的一段 83.5 秒采样中，nvidia-smi 报 GPU 功率均值 187.36 W、峰值 312.17 W，据此**估算**电量约 4.35 Wh。该值仅代表 pilot 中这一个采样段，不含 CPU/内存/网络，点采样非连续积分，**不得**解释为整轮实验或整机能耗。
