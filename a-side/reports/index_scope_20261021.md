# 索引口径裁定（index_scope_20261021）

日期：2026-10-21｜性质：**离线裁定，不重跑实验、不读 gold、不开 GPU**
输入（只读）：`uclanlp/MRAG-Bench@43620fde` 的 28 个 parquet 分片（仅计数，不解码图像）、`corpus_v1`（`corpus_manifest.csv` / `occurrences.csv` / `corpus_meta.json`）、B 侧回执字段（已核实，直接作输入）。

## 0. 裁定结论（一句话）

**论文口径用 `14,475`（可自证的图像实例数）与 `4,712`（可自证的唯一内容数）；`18,955` 只能作为"已发布索引行数"出现，并加脚注说明其构成未在公开数据上自证。三个数不得混写为同一个量。**

## 1. 三个数各是什么（逐项可追）

| 数 | 是什么 | 怎么自证（文件→行） |
|---:|---|---|
| **14,475** | **图像实例数**：1,353 题 × (1 张查询图 + 平均 GT + 5 张官方候选) 展开后的行数 | 逐 parquet 统计：`test-00000-of-000028.parquet` … `test-00027-of-000028.parquet` 共 28 个文件；`id` 行合计 **1,353**，`gt_images` 列表长度合计 **6,357**，`retrieved_images` 列表长度合计 **6,765**。1,353 + 6,357 + 6,765 = **14,475**（逐分片明细见 `order_diff_20261021/census.json` 的 `per_shard`） |
| **4,712** | **唯一内容数**：按内容身份去重后的图像数 | `corpus_v1/corpus_manifest.csv` 数据行 = **4,712**（按 `sha256` 升序，一行一内容）；`corpus_v1/occurrences.csv` 数据行 = **14,475**（一行一实例，与上一行数相等即证明是同一语料的两种视图） |
| **18,955** | **已发布 smoke 报告的索引行数**（B 侧回执 `index.entries` 同值） | **无法用公开数据复核**：既不是 14,475（实例），也不是 4,712（唯一内容） |

### 1.1 实例 14,475 的构成

```
1,353 张查询图（每题 1 张，image 字段）
+ 6,357 张 GT 实例（gt_images：1,251 题各 5 张 + 102 题各 1 张）
+ 6,765 张官方候选实例（retrieved_images：1,353 题各 5 张）
= 14,475 个图像实例
```

- 重复度：14,475 − 4,712 = **9,763** 个实例是"同一内容在别的题/别的角色下再次出现"（`occurrences.csv` 里同一 `sha256` 出现多次）。**这 9,763 不是新图**，只是同图多实例。
- 所以 `corpus_v1` 只保留 4,712 行（按内容去重）。

### 1.2 两个差的构成

| 差 | 算术 | 是否可自证 | 说明 |
|---|---:|---|---|
| 18,955 − 14,475 = **4,480** | — | **不可自证** | 不能拆成"多出的 4,480 张图"。B 侧回执称 `dedup.by_identity=true`、`kept_duplicates=0`，即索引内 18,955 个身份互不重复；与"14,475 个实例中有 9,763 个重复"这一事实**不兼容**，说明索引里存在**不属于这 14,475 个实例的内容** |
| 18,955 − 4,712 = **14,243** | — | **不可自证** | 同上。注意 4,480 + 9,763 = 14,243 只是算术恒等，**不构成解释**：它说明"若把 9,763 个重复实例也各留一行，再加 4,480，就得到 18,955"，但没有任何证据表明索引是这么建的 |

**明确写死**：这两个差**不得**被解释为"额外语料"或"重复副本"，除非 `sources[]` 给出证据。目前的唯一可判定事实是：**18,955 与两个可复核口径都不等**。

## 2. 为什么不能改用 18,955 作论文口径

| 判据 | 14,475 | 4,712 | 18,955 |
|---|---|---|---|
| 有公开文件与行可逐步复算 | ✅ 28 个 parquet 逐行 | ✅ `corpus_manifest.csv` 4,712 行 | ❌ 无 |
| 与 `occurrences.csv` 行数自洽 | ✅ 14,475 = 9,763 重复 + 4,712 唯一 | ✅ | ❌ 与两者都不自洽 |
| 别人拿到公开数据能独立复现 | ✅ | ✅ | ❌ 需要 B 的私有索引文件 |
| 可用于论文正文的定量陈述 | ✅ "实例数" | ✅ "唯一内容数" | ⚠ 只能作"发布索引行数"并加脚注 |

裁定：**论文正文用 14,475 / 4,712；18,955 只出现在脚注与结果表的环境描述里。**

## 3. 可直接进论文脚注的中文原文

> 本实验的检索语料取自 MRAG-Bench 官方发布（revision `43620fde4044bb150e158c67ad7af6b6b11e1da2`，`test` 划分）。按题目展开，该划分共含 **1,353** 道题、**14,475** 个图像实例（1,353 张查询图、6,357 个 GT 实例、6,765 个官方候选实例）；按图像内容（sha256）去重后为 **4,712** 个唯一内容，其余 9,763 个实例是同一内容在不同题目或不同角色下的重复出现。本文所报告的一切检索指标与语料规模均以上述经去重的 4,712 个唯一内容构成的索引为基础。我们另在使用的外部技术验证（同机端到端 smoke）中沿用了其发布时记录的索引，该记录报告索引行数为 **18,955**；由于该索引不属于本划分的可复核口径（按实例为 14,475、按内容为 4,712），其行数仅作为发布索引的元信息在此注明，**不用于**本文任何语料规模或检索指标的定量陈述。

（如需更短版本，去掉最后一句的"其行数仅作为…"即可，但**不要**删掉"不用于"那半句。）

## 4. 不可自证的部分与缺的输入

| 缺的输入 | 用途 |
|---|---|
| `index_receipt.sources[]`：额外语料的 `path` / `sha256` / 规模 | 判定 18,955 的 14,243 / 4,480 从哪来（是作者语料、还是别的 gallery） |
| `index.artifact_files[]` 的逐文件 `sha256` 与行数 | 确认索引文件本身确为 18,955 行（而非报告笔误） |
| 若 `identity.rule=sha256_raw_bytes`：额外内容与数据集图像是否有交集 | 区分"同图不同字节"与"完全新的图" |

在上述三项到位前，本裁定只到"**18,955 不可自证，只作发布索引行数**"这一步，不做进一步归因。
