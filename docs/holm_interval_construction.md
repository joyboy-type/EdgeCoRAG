# Holm 与同时置信矩形的构造说明

本轮既报告 Holm step-down 校正的双侧 centered-bootstrap p 值，也报告与整族联合接受域相容的保守同时置信矩形。两者不是同一个对象。

Holm 对某个候选参数向量“不拒绝任何一个原假设”，当且仅当所有原始 p 值均大于 alpha/m。因此对整个家族联合接受域作矩形投影，退回 Bonferroni 的边际置信水平。这是一种保守且明确定义的 Holm 兼容区间构造，不冒称按观察 p 值排序便可以获得有同时覆盖保证的更窄区间。

数值采用题目加权、成分有放回的 basic bootstrap 区间：2×原始差值减去bootstrap分布的上下分位数。未校正为95%，同时矩形为1−0.05/m。10000次重采样与线性分位数给出的是描述性近似区间；p值使用+1有限重采样修正，区间不被称为有限样本精确置信集。表内 `holm_ci_*` 字段必须连同该方法说明引用。不能只截取字段名而隐去“联合接受域矩形/数值等同Bonferroni/描述性近似”的限定。

Oracle配对均标注post hoc，与可部署路径分开解释；任何区间包含0时写“不能排除无差异”。没有预注册非劣效界值，也没有把区间包含0解释为等价。
